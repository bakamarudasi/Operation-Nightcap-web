## 1. コンセプト

**ジャンル：** 探索ふれあいアドベンチャー（アダルト）
**リファレンス：** 黒先輩と黒屋敷の闇に迷わない
**エンジン：** Godot 4.x / GDScript
**プレイ時間：** 1周 約2〜3時間（3キャラ分のルートで計6〜9時間）
**舞台：** ラテラーノ教皇庁の地下遺跡（封鎖された前文明施設）

### あらすじ
ラテラーノ教皇庁の地下で前文明の遺跡が発見された。禁忌アーツの痕跡を調査するため、ロドスから派遣された連絡官（プレイヤー）は、サンクタのオペレーター1人と共に遺跡に潜入する。しかし入口が崩落で塞がれ、二人きりで遺跡の奥へ進むしかなくなった——。

閉鎖空間で二人きり。謎を解いて脱出する……その間、**いつでもどこでもオペレーターにちょっかいを出せる**。

### 黒先輩リスペクトの核
- **見下ろしマップ**をプレイヤーが移動し、オペレーターが後ろからついてくる
- **メニューを開ける場所ならいつでも「ふれあいコマンド」**が使える
- **場所・進行度・イベントフラグ**で触れるバリエーションが変化する
- **探索・謎解きは簡単**。メインの楽しさは「ふれあい」と「反応を見ること」
- オペレーターがヒントをくれたり、一緒に考えてくれたりもする

## 2. ゲーム構造

### ルート選択
タイトル画面後、**同行するオペレーターを1人選ぶ**。選んだキャラでストーリーと謎解きが変化。

| ルート | 同行者 | 難易度 | 特徴 |
|--------|--------|:------:|------|
| **音律の回廊** | ヴィルトゥオーサ | ★☆☆ | 音と感覚がテーマ。感応アーツで謎を解く |
| **天使の銃声** | エクシア | ★☆☆ | 射撃と行動力がテーマ。ノリとテンポで突破 |
| **枢機卿の判断** | レミュアン | ★★☆ | 情報と推理がテーマ。姉としての一面も |

※どのルートも1周2〜3時間。全ルートクリアでボーナスシーン解放。

### マップ構成（共通骨格）

```
【地下遺跡 全体マップ】

  入口（崩落で封鎖）
    │
  ① エントランスホール ─── 管理室
    │
  ② 回廊（東翼／西翼分岐）
    │         │
  ③ 研究区画  ④ 居住区画
    │         │
  ⑤ 大広間（中央）
    │
  ⑥ 動力室
    │
  ⑦ 最深部（前文明の祭壇）
    │
  脱出路
```

- 全7エリア＋サブルーム（各エリア2〜3部屋）
- ルートごとに一部の部屋・謎・イベントが差し替わる
- 各エリアに**調べられるポイント**が5〜10個
- 鍵アイテム・パズル・ストーリーテキストが配置

## 4. ふれあいコマンドシステム（核心）

### 立ち絵方向連動システム（Godotならではの独自要素）

**プレイヤーのマップ上の位置に応じて、画面右の立ち絵がリアルタイムに切り替わる。**
RPGツクールでは不可能な、Godot独自のシステム。

プレイヤーとオペレーターの相対角度を`atan2`で算出し、3方向に分類：

| 判定 | 角度範囲 | 立ち絵 | 見つめ/触れられる部位 |
|------|---------|--------|---------------------|
| **正面** | ±60° | 前面 | 顔・胸・お腹 |
| **側面** | 60°〜120° / -60°〜-120° | 横向き（左右反転で共用） | 横顔・腰・翼の付け根 |
| **背後** | 120°〜240° | 背面 | 髪・背中・お尻・翼 |

※立ち絵は画面右側に常時表示。マップ上のキャラとは別にUI層で表示。

**方向ごとの反応テキスト例（ヴィルトゥオーサ）：**

| コマンド | 正面 | 背後 |
|---------|------|------|
| 見つめる→胸/お尻 | 「…あなた今、どこを見てるか当てましょうか？」 | 「——…後ろにいるの、わかってるわよ？ …何を見てるの」 |
| 触れる→肩/背中 | 「ん、何？」 | 「…っ、背中は不意打ちよ」 |
| 触れる→翼 | （正面からは届かない） | 「っ…！ 翼は…ダメ…っ、繊細なの…」 |

**サンクタの翼設定との連携：**
- サンクタの翼は魂に近い器官（公式設定で光輪＝魂の一部）
- 背後からしか触れない＝特別感＋背徳感
- 翼への反応は全キャラ共通で**最も大きいリアクション**

**必要立ち絵枚数（方向追加分）：**
- 1キャラあたり：前面 + 背面 + 横向き = 3方向
- 横向きは左右反転で使い回し
- 各方向 × 表情差分8種 = **1キャラ24枚**（レイヤー分離で効率化）
- 3キャラ合計 = **72枚**

### 基本仕様
- **メニューボタン（またはキー）でいつでも「ふれあいメニュー」を開ける**
- メニューを開くとオペレーターがこちらを向き、コマンド選択画面に
- コマンド実行 → オペレーターのリアクション（テキスト＋表情変化＋SE）
- **同じコマンドでも場所・進行度・フラグで反応が変わる**

### コマンド一覧（方向連動）

コマンドはプレイヤーの位置（正面/側面/背後）で変化する。

**【共通コマンド（どの方向でも使える）】**

| コマンド | 説明 |
|----------|------|
| **💬 話しかける** | 場所ごとに話題変化。ヒントもここ |
| **🤗 抱きしめる** | Lv.2以降解放 |
| **🎁 プレゼント** | 探索で拾ったアイテムを渡す |

**【正面コマンド】**

| コマンド | 説明 |
|----------|------|
| **👁 顔を見つめる** | 表情変化が見える |
| **👁 胸を見つめる** | 序盤は即バレ |
| **✋ 頭を撫でる** | 定番 |
| **✋ 胸に触れる** | ハイリスクハイリターン |
| **✋ お腹に触れる** | 距離感が近い |

**【背後コマンド】**

| コマンド | 説明 |
|----------|------|
| **👁 背中を見つめる** | 無防備な後ろ姿 |
| **👁 お尻を見つめる** | 背後ならではの背徳感 |
| **✋ 髪に触れる** | 後ろからそっと |
| **✋ 背中に触れる** | 不意打ち感が強い |
| **✋ 翼に触れる** | 🔥最大リアクション。サンクタの魂に近い器官 |

**【側面コマンド】**

| コマンド | 説明 |
|----------|------|
| **👁 横顔を見つめる** | 横顔の美しさ |
| **✋ 腰に触れる** | さりげない接近 |
| **✋ 翼の付け根に触れる** | 翼の根元＝超敏感 |

### 「見つめる」の部位別反応（例：ヴィルトゥオーサ）

| 部位 | 序盤 | 中盤 | 終盤 |
|------|------|------|------|
| 顔 | 「何？ 私の顔に何かついてる？」 | 「…そんなに見つめられると、さすがに気になるわ」 | 「ふふ、見つめ合うのも悪くないわね」 |
| 胸 | 「…視線が低いわよ？」 | 「もう、わかっててやってるでしょう」 | 「そんなに気になる？…後でね」 |
| 脚 | 「足元が気になるの？」 | 「じろじろ見ないでくれるかしら」 | 「…好きに見ていいわよ」 |
| 翼 | 「翼に興味がある？サンクタの翼は繊細なの」 | 「触りたい…？ダメよ、くすぐったいの」 | 「あなたになら…少しだけ」 |
| 光輪 | 「光輪はサンクタの魂みたいなものよ」 | 「光輪を見ると落ち着く…？不思議ね」 | 「あなたに見つめられると、少し光が強くなるの」 |

### 場所限定の特殊ふれあい

| 場所 | コマンド | 内容 |
|------|---------|------|
| 居住区画のベッド | 「一緒に休む？」 | 並んで座って会話 → 進行度で展開変化 |
| 研究区画の実験台 | 「アーツの実験しない？」 | ヴィルトゥオーサ限定：感応アーツ体験 |
| 大広間のピアノ | 「弾いてくれない？」 | ヴィルトゥオーサ限定：演奏イベント |
| 動力室の暗闘 | 「怖い？」 | エクシア限定：暗闇で距離が近くなる |
| 管理室の執務机 | 「仕事中の顔も素敵だね」 | レミュアン限定：照れながら資料説明 |
| 最深部の祭壇前 | 「お願いがある」 | 全キャラ共通：告白的イベント（Hシーン前提） |

### ふれあいが許容される理由（キャラ別アプローチ）

**基本方針：ギャグ寄りで深く説明しない。でも反応は段階的にリアルに変化する。**

「なぜ触れるのか」は設定で重く説明せず、キャラの性格で自然に処理する。
序盤に怒られる・呆れられるのも楽しみの一部。終盤のデレとの落差がゲームの快感。

**ヴィルトゥオーサ：「余裕ぶり → 余裕崩壊」型**
- 感応アーツで相手の感情が読めるため、何をされても「ふふ、面白い人ね」と余裕で受け流す
- 「あなたの感情は筒抜けよ？ 隠しても無駄」というスタンス
- 序盤：こちらの意図をすべて見透かした上で余裕の微笑み
- 中盤：「…あら、今のは少し予想外だったわ」と余裕にヒビ
- 終盤：感応アーツで自分の感情も流れ込んでしまい、余裕が完全に崩れる
- ギャグ要素：「今あなた、○○なこと考えたでしょう」と心を読んでツッコミ

**エクシア：「ノリツッコミ → 照れツッコミ弱体化」型**
- 元々ノリがいいので「なにやってんのドクター！ｗ」とツッコミで流す
- 序盤：「やめろって！ｗ まったくもう！」と明るくはたく
- 中盤：「だーかーらー！…まあいいけど」とツッコミのキレが落ちる
- 終盤：「…っ、もう好きにしろよバカ」と照れ隠しすらできなくなる
- ギャグ要素：ツッコミのバリエーションが無駄に豊富。「アップルパイにされたいのか！？」等

**レミュアン：「上司の呆れ顔 → 冷静崩壊」型**
- 枢機卿としての器のデカさで「…それで気が済むなら好きにしなさい」と呆れスルー
- 序盤：完全に「部下の奇行を見る上司の目」。冷静な溜息
- 中盤：「…あなた、本当にロドスの正規職員？ 人事に確認するわよ」と牽制しつつ、怒らない
- 終盤：こちらを意識してしまい、冷静な分析が崩れる。「…っ、今のは予測できなかった」
- ギャグ要素：ふれあいを「行動分析」として冷静にレポートしようとする。「接触回数が統計的に異常値を示している」

### ふれあい進行度（内部フラグ）

| 段階 | 触れ合い回数目安 | 解放要素 |
|------|:---:|------|
| Lv.0 警戒 | 0 | 基本コマンドのみ。塩対応多め |
| Lv.1 容認 | 10回 | 反応が柔らかくなる。「話しかける」で私的な話題 |
| Lv.2 好意 | 25回 | 「抱きしめる」解放。特殊反応増加 |
| Lv.3 信頼 | 50回 | 場所限定コマンド全解放。終盤イベント条件 |
| Lv.4 絆 | ストーリー条件 | Hシーン解放。エンディング分岐 |

※ふれあい回数は「見つめる」「話しかける」以外をカウント。ストーリー進行でもボーナス加算。

## 5. 探索・謎解きパート

### 基本操作
- **矢印キー/WASD：** プレイヤー移動（見下ろし2Dマップ）
- **決定キー/クリック：** 調べる、話しかける、アイテム取得
- **メニューキー：** ふれあいコマンド＋アイテム確認＋セーブ

### オペレーターの同行AI
- プレイヤーの後ろを1〜2マス離れてついてくる
- 調べられるポイントの近くで立ち止まると、自発的にコメントすることがある
- 特定のポイントではオペレーターが「ここ、気になるわ」等で注意を促す（ヒント機能）
- 何度も話しかけると段階的にヒントが具体化する（黒先輩方式）

### 謎解き難易度
- **全体方針：サクサク進める簡単さ**
- 詰まっても同行オペレーターに聞けば段階的ヒント
- 各エリアの謎は1〜2個、5分以内で解ける程度
- 鍵アイテムは光って分かりやすい

### 謎解き例（エリアごと）

| エリア | 謎 | 解法 |
|--------|-----|------|
| エントランス | 扉のロックパネル | 部屋にある石板の数字を入力 |
| 回廊 | 光る床タイル | 壁の模様と同じ順番で踏む |
| 研究区画 | 薬品棚のパズル | メモにある色の順番で瓶を並べる |
| 居住区画 | 日記の暗号 | アルファベットシフト（ヒント付き） |
| 大広間 | 像の向き合わせ | 壁画の図と一致させる |
| 動力室 | 配線パズル | 色を合わせて繋ぐ |
| 最深部 | 最終パズル | ルートごとに異なる（音/射撃/暗号） |

## 7. アーツ設定（ゲーム内活用）

### 感応アーツの段階（ヴィルトゥオーサルート固有）
遺跡内の前文明装置が感応アーツを増幅する設定。ストーリー進行で段階的に深まる。

| 段階 | エリア | 演出 |
|------|--------|------|
| 表層共鳴 | エントランス〜 | 彼女の感情が「色」として見える演出（テキスト表現） |
| 感覚共有 | 研究区画〜 | ふれあい時に「相手の感覚」も伝わる描写が追加 |
| 深層同調 | 大広間〜 | 記憶の断片共有イベント。ヴィルトゥオーサの過去 |
| 完全共鳴 | 最深部 | Hシーンで感覚が完全同期する演出 |

### エクシアルート
- アーツ要素は控えめ。代わりに**銃と光輪の共鳴**（サンクタの銃＝魂の一部設定）がテーマ
- 遺跡の射撃パズルを解くうちに、エクシアの銃への想いと家族への想いが語られる

### レミュアンルート
- 教皇庁の情報分析能力で遺跡の文書を解読していく
- 第七庁が把握していた**禁忌アーツ事件の真相**が明らかに
- 枢機卿としての仮面が剥がれていく過程がメイン

### コア技術

| 要素 | 実装方針 |
|------|---------|
| **マップ** | TileMapLayer（Godot 4.x）で見下ろし2D。32x32 or 48x48タイル |
| **プレイヤー移動** | CharacterBody2D + Input.get_vector()。8方向 or 4方向 |
| **同行AI** | CharacterBody2D。プレイヤーの移動履歴を保持し、数フレーム遅れで追従。NavigationAgent2Dで障害物回避 |
| **調査ポイント** | Area2D + InteractionIcon。プレイヤー接近で「！」表示 → 決定キーで調査 |
| **ふれあいメニュー** | CanvasLayer上のControl。メニュー展開時にゲーム一時停止。コマンド選択 → reaction_db.gdから条件に合うテキスト取得 |
| **反応テキストDB** | JSON。キー = キャラID + コマンド + 部位 + 進行段階 + エリア。フォールバック付き |
| **会話ウィンドウ** | RichTextLabel + BBCode。文字送り演出（Timer + visible_characters） |
| **立ち絵表示** | TextureRect。ふれあいメニュー時に画面右側に大きく表示。表情差分切り替え |
| **CG表示** | 全画面TextureRect + テキストオーバーレイ。差分はテクスチャ切り替え |
| **セーブ** | JSON → user://saves/。エリア + 座標 + フラグ + ふれあいLv + アイテム |

## 11. 素材リスト

### アセット制作パイプライン

**方針：歩行スプライトはAI生成、立ち絵・CGは手描き/自作**

#### 歩行スプライト（AI生成）
- **ツール候補：** God Mode AI / Ludo.ai / ComfyUI+SD
- **方式：** テキストプロンプト or img2img → スプライトシート出力
- **サイズ：** 32×32 or 48×48ピクセル
- **必要数：** 4キャラ × 4方向 × 3フレーム = 48コマ（スプライトシート4枚）
- **キャラ識別の方針（小さいので色とシルエットで区別）：**
  - ドクター：白/黒系コート、フード
  - ヴィルトゥオーサ：金髪＋白い翼＋黒い服
  - エクシア：赤髪＋白い翼＋明るい服＋銃
  - レミュアン：黒髪＋白い翼＋フォーマルな服
- **注意：** 完全な原作再現は不要。「それっぽく見える」を優先

#### 立ち絵（自作 — 手描き or AI生成＋手修正）
- **方向：** 3方向（前面・背面・側面）×横は左右反転で共用
- **表情差分：** 8種（通常/照れ/怒り/驚き/喜び/艶/目閉じ/特殊）
- **必要数：** 3キャラ × 3方向 × 表情8種 = **72枚**（レイヤー分離で効率化）
- **レイヤー構成案：**
  - ベース体（方向ごと）
  - 衣装（差し替え可能）
  - 表情（目・口・眉の組み合わせ）
  - 翼（方向で形状変化）
  - 光輪（常時表示、エフェクト）

#### イベントCG（自作）
- 3キャラ × 5枚（通常2＋H用3）、各差分2〜3
- 合計 **15枚＋差分**

#### マップタイルセット
- AI生成 or フリー素材ベース＋手修正
- 前文明遺跡風（石壁、装置、光る源石等）
- 32×32 or 48×48統一

#### UIパーツ
- メニュー、ウィンドウ、アイコン → コード側で構築（フォント＋ColorRect）可
- 凝るなら後からデザイン差し替え

## 12. ラテラーノ地下遺跡の設定

### 公式準拠
- ラテラーノの地下に前文明（先民）の遺構が存在するのは公式の余白として矛盾しない
- ロドスアイランドの船体自体が前文明製であり、ラテラーノにも同様の遺跡があってもおかしくない
- 前文明の技術はオリジニウムアーツと異なる原理で動作する（公式設定）

### ゲーム独自設定
- **遺跡は教皇庁が秘密裏に管理していた前文明の感応研究施設**
- かつてサンクタの精神に干渉する実験が行われていた
- 感応アーツの源流がここにある → ヴィルトゥオーサのアーツとの関連
- 遺跡の装置がまだ稼働しており、滞在者の感情を増幅する（ふれあい反応が進行で変化する世界観的理由）
- 「感情が増幅される閉鎖空間で二人きり」＝ゲーム全体の状況設定
